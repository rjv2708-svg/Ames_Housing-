# Ames Housing Price Prediction using Machine Learning

## Project Description
This project aims to predict house prices (Sale Price) in Ames, Iowa, using various modern Machine Learning Regression techniques. The model analyzes multiple features of a house to estimate its market value accurately.

## Project Workflow
1. **Data Preprocessing:** Handled missing values, treated outliers, and performed categorical encoding.
2. **Feature Engineering:** Selected top correlated features and applied transformations.
3. **Model Training:** Trained multiple regression algorithms to find the best fit.
4. **Evaluation:** Compared models based on R2 Score and RMSE (Root Mean Squared Error).

## Tech Stack & Libraries
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn, XGBoost

## Algorithms Evaluated
* Linear Regression
* Ridge / Lasso Regression
* Random Forest Regressor
* Gradient Boosting (XGBoost)
